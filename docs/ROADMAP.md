# Roadmap

[← README](../README.md) · [简体中文](../README.zh-CN.md)

These ideas carry forward the project's existing roadmap. They are not available in the current app, and there are no promised release dates. See the [changelog](../CHANGELOG.md) for shipped features.

- [ ] A 24-hour / 12-hour display toggle.
- [ ] Direct copying of the current UTC timestamp, including Unix epoch and ISO 8601 / RFC 3339.
- [ ] ISO 8601 or custom format strings in the menu bar.
- [ ] Free-text prefixes and suffixes, plus a full emoji picker.
- [ ] Global hotkeys for the popover, Settings, or converter.
- [ ] Mac App Store distribution.
- [ ] Developer ID signing and Apple notarization for release builds.

Lower-priority ideas:

- [ ] Multiple time zones in the menu bar; this would expand the app's scope.
- [ ] More decorators, colors, and per-glyph styling.

Universal app downloads and in-app updates are already available.
